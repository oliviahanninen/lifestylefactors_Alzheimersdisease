# lifestylefactors_Alzheimersdisease
The main objective of this study is to compare the prevalence of Alzheimer’s disease across different ethnicities based on lifestyle factors. How do different lifestyle factors influence the likelihood of an Alzheimer’s disease diagnosis?

# Technologies Used
* Python
* Pandas, NumPy, Seaborn, Scipy
* Matplotlib

# Features
* Cleans and checks the raw data from CSV-file.
* Calculates overall impact of lifestyle factors.
* Creates correlation matrices to investigate potential relationships between ethnicity, lifestyle factors, and Alzheimer’s disease prevalence.
* Employs ANOVA and decision trees to further investigate correlations.
* Generates visual graphs for analysis.

2,149 patients from four ethnic groups.
Each patient record includes 34 variables, of which 10 were initially selected for analysis. The chosen variables include gender, ethnicity, body mass index (BMI), smoking status, alcohol consumption, physical activity, diet quality, sleep quality, and Alzheimer’s disease diagnosis outcome.
